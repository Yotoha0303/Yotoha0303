# 独立开发者客户沟通与反白嫖三秒回复话术库 (Canned Responses)

> **设计目标**：针对闲鱼、电鸭、V2EX 挂单后的真实询单场景，建立秒级标准化响应机制，**彻底杜绝“人肉客服泥潭”与无休止的需求扯皮**，将白嫖与非标询盘挡在第一道门外。

---

## 一、 白嫖与低价骚扰拦截模板 (Filter Free-loaders)

### 场景 1：预算严重不足（“老哥 50 块能帮我扒个网站吗？”）
```text
您好，抱歉接不了。我们所有技术交付均执行标准化工程规范（含完整源码、48小时交付 SLA、单元测试验收与售后修复），最低起步价为 1,500 元。如果预算有限，建议您尝试开源免代码抓取工具（如 Web Scraper 插件），感谢咨询！
```

### 场景 2：要求无偿先写 Demo（“能先写个 Demo 看看效果再付钱吗？”）
```text
您好，我们不支持未签约编写 Demo。我们所有服务包均包含经过验证的公开开源证据库（超过 5 万行代码、1,800 项单测全部绿灯）。您可以先查看我们的代码样本与架构说明：https://github.com/Yotoha0303/Yotoha0303
确认符合您的技术期望后，我们走平台官方订单托管：您下单托管全额款项 -> 48小时内我们交付源码与可运行样例 -> 跑通且符合验收标准后您再确认收货放款。双方权益完全由平台担保。
```

### 场景 3：需求极其模糊（“我想要一个类似抖音/微信的系统，大概多少钱？”）
```text
您好，我们专注于固定范围、轻量级工程模块交付。为了准确评估档期和可行性，请您提供以下 3 项基本信息：
1. 具体的输入数据样例（如网页地址、API 接口文档或数据样例）；
2. 期望的输出格式（如 CSV 表格、JSON 结构或 SQLite 数据库）；
3. 关键业务指标（如请求频率、数据量级、部署环境）。
收到以上具体资料后，我们会在 1 小时内给您明确的固定报价与交付档期。
```
